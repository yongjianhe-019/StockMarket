# 择时策略：冰点买入 + 泡沫卖出

基于 **A股估值指标 + 全球宏观指标** 双引擎的 ETF 左侧投资系统。

## 投资哲学

```
不做个股 → ETF 降噪
不做高频 → 月度信号
不做右侧追涨 → 左侧等冰点
不凭感觉 → 量化驱动

冰点出现 → 分批买入 → 长期持有 → 泡沫出现 → 减仓
```

## 信号定义

### 🧊 冰点（买入）

| ETF | 触发条件 | 含义 |
|---|---|---|
| 沪深300 | 分数 ≥ 50（PE/PB分位+回撤+量价+波动） | 估值便宜，左侧建仓 |
| 中证2000 | 分数 ≥ 50（宏观流动性+趋势动量+相对强弱） | 流动性充裕+趋势向好 |

### ⚠️ 泡沫（卖出）

**前提：PE 分位必须 > 60%（估值必须先贵）**

同时 ≥2 个宏观恶化信号：
- 中美利差急剧扩大（>0.5%/半年）
- 人民币快速贬值（>3%/3月）
- 黄金异常飙升（>15%/3月）
- M2 急剧收紧
- 美联储意外加息
- 社融大幅收缩

### — 持有

不满足买入也不满足卖出 → 耐心持有。

## 模型优化日志

### v3 (2026-08-11) — 冰点增强 + 泡沫检测重写

**核心原则不变：左侧冰点播种，泡沫分批收割。**

四个优化：

| 模块 | 优化 | 来源 | 效果 |
|------|------|------|------|
| CSI300 冰点 | +ERP极端信号加分(+15) | 广发证券：ERP达均值+2σ是历史大底 | 深冬识别更准（2022年最高90分） |
| CSI300 冰点 | +宏观底部确认加分(+5) | 华泰证券：PMI/M2不再恶化=底部确认 | 微观估值+宏观共振 |
| CSI2000 冰点 | +趋势质量过滤(R²<0.3动量打折) | 小盘反弹假信号多 | 买入从16次降至14次，去噪音 |
| 泡沫检测 | 三分类确认：A价格加速+B量价背离+C宏观恶化 | 广发/东吴/经典量价 | 12年检测到14次部分信号，0次误触 |

**泡沫分级卖出机制：**

| 等级 | 条件 | 卖出比例 |
|------|------|:--:|
| 轻度泡沫 | 2类触发，3~4个信号 | 25% |
| 中度泡沫 | 2类触发，5~6个信号 | 50% |
| 严重泡沫 | ≥2类触发，7+个信号 | 75% |

**冰点分档买入机制：**

| 分数 | 季节 | 仓位 |
|------|------|:--:|
| 80~100 | 深冬 ❄️ | 65% |
| 70~79 | 冬天 🥶 | 50% |
| 60~69 | 初冬 🌨️ | 35% |
| 55~59 | 秋末 🍂 | 25% |
| 50~54 | 霜降 🌫️ | 15% |

所有市场指标数据来源于akshare，宏观数据包括23个因子，指数日线、PE/PB估值、国债收益率、汇率、黄金、M2、社融、CPI、PMI、美联储利率、房地产景气等。每日更新。
