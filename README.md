# 择时策略：冰点买入 + 泡沫卖出

基于 **A股估值指标 + 全球宏观指标** 双引擎的 ETF 左侧投资系统。

## 投资哲学

```
不做个股 → ETF 降噪
不做高频 → 月度信号
不做右侧追涨 → 左侧等冰点
不凭感觉 → 量化驱动

冰点出现 → 分批买入 → 长期持有 → 泡沫出现 → 减仓
```

## 信号定义

### 🧊 冰点（买入）

| ETF | 触发条件 | 含义 |
|---|---|---|
| 沪深300 | 分数 ≥ 50（PE/PB分位+回撤+量价+波动） | 估值便宜，左侧建仓 |
| 中证2000 | 分数 ≥ 50（宏观流动性+趋势动量+相对强弱） | 流动性充裕+趋势向好 |

### ⚠️ 泡沫（卖出）

**前提：PE 分位必须 > 60%（估值必须先贵）**

同时 ≥2 个宏观恶化信号：
- 中美利差急剧扩大（>0.5%/半年）
- 人民币快速贬值（>3%/3月）
- 黄金异常飙升（>15%/3月）
- M2 急剧收紧
- 美联储意外加息
- 社融大幅收缩

### — 持有

不满足买入也不满足卖出 → 耐心持有。
