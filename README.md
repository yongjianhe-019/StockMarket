# 择时策略：冰点买入 + 泡沫卖出

基于 **A股估值指标 + 全球宏观指标** 双引擎的 ETF 左侧投资系统。

## 投资哲学

```
不做个股 → ETF 降噪
不做高频 → 月度信号
不做右侧追涨 → 左侧等冰点
不凭感觉 → 量化驱动

冰点出现 → 分批买入 → 长期持有 → 泡沫出现 → 减仓
```

## 信号定义

### 🧊 冰点（买入）

| ETF | 触发条件 | 含义 |
|---|---|---|
| 沪深300 | 分数 ≥ 50（PE/PB分位+回撤+量价+波动） | 估值便宜，左侧建仓 |
| 中证2000 | 分数 ≥ 50（宏观流动性+趋势动量+相对强弱） | 流动性充裕+趋势向好 |

### ⚠️ 泡沫（卖出）

**前提：PE 分位必须 > 60%（估值必须先贵）**

四分类检测，≥2 类触发 → 泡沫确认：

| 类别 | 信号 |
|---|---|
| A 价格加速 | 6月涨幅>30% / 偏离MA60>30% / 动能衰竭 |
| B 量价背离 | 近高点量缩 / 价升量缩 / 天量后急缩 |
| C 宏观恶化 | 利差扩大 / 人民币贬值 / 黄金飙升 / M2收紧 / 加息 / 社融收缩 |
| D 流动性狂热 | 两融6月增速>50% / 成交量20日vs年均>2.5倍 |

### 📉 趋势破坏（独立风控信号，非泡沫）

PE 分位 > 60% 且 跌破MA60且MA60拐头 → 减仓50%（检测器漏判时的保险丝，PE<60%永不激活）

### — 持有

两个极端信号（冰点/泡沫）均未触发 → 中间态，不操作。

## 模型优化日志

### v3 (2026-08-11) — 冰点增强 + 泡沫检测重写

**核心原则不变：左侧冰点播种，泡沫分批收割。**

四个优化：

| 模块 | 优化 | 来源 | 效果 |
|------|------|------|------|
| CSI300 冰点 | +ERP极端信号加分(+15) | 广发证券：ERP达均值+2σ是历史大底 | 深冬识别更准（2022年最高90分） |
| CSI300 冰点 | +宏观底部确认加分(+5) | 华泰证券：PMI/M2不再恶化=底部确认 | 微观估值+宏观共振 |
| CSI2000 冰点 | +趋势质量过滤(R²<0.3动量打折) | 小盘反弹假信号多 | 买入从16次降至14次，去噪音 |
| 泡沫检测 | 三分类确认：A价格加速+B量价背离+C宏观恶化 | 广发/东吴/经典量价 | 12年检测到14次部分信号，0次误触 |

**泡沫分级卖出机制：**

| 等级 | 条件 | 卖出比例 |
|------|------|:--:|
| 轻度泡沫 | 2类触发，3~4个信号 | 25% |
| 中度泡沫 | 2类触发，5~6个信号 | 50% |
| 严重泡沫 | ≥2类触发，7+个信号 | 75% |

**冰点分档买入机制：**

| 分数 | 季节 | 仓位 |
|------|------|:--:|
| 80~100 | 深冬 ❄️ | 65% |
| 70~79 | 冬天 🥶 | 50% |
| 60~69 | 初冬 🌨️ | 35% |
| 55~59 | 秋末 🍂 | 25% |
| 50~54 | 霜降 🌫️ | 15% |

所有市场指标数据来源于akshare，宏观数据包括23个因子，指数日线、PE/PB估值、国债收益率、汇率、黄金、M2、社融、CPI、PMI、美联储利率、房地产景气等。每日更新。

### v4 (2026-08-12) — 泡沫检测补盲区 + 信号分层 + 数据可靠性治理

**v3 病灶暴露（2015专项回测）**：2015股灾前泡沫检测 0 次触发，满仓扛过 -45% 回撤。
根因：B类量价背离/C类宏观恶化在杠杆快泡沫中永不触发（2015是量价齐升+宏观无恙），≥2类确认门槛永远凑不满。

**五个改动：**

| 模块 | 优化 | 效果 |
|------|------|------|
| 泡沫检测 | +D类「流动性狂热」：两融6月增速>50% + 成交量20日/年均>2.5倍 | 识别2015式杠杆快泡沫（两融数据源：证金公司官方，日频T日盘后） |
| 泡沫检测 | +趋势破坏兜底：PE>60%分位 + 跌破MA60且拐头 → 减仓50% | A/B/C/D全部漏判时的保险丝；PE<60%时永不激活（不会在便宜大底误卖） |
| 信号分层 | 泡沫(`signal_type=bubble`) 与 趋势破坏(`signal_type=trend_breakdown`) 分开命名 | 两个极端信号（冰点/泡沫）+ 独立风控信号，中间态不操作 |
| 数据治理 | 新开户数信号弃用（东财管道2023-08后冻结） | 管道不可信的数据宁缺毋滥；移除后2015卖出全保留，仅丢2021-03逃顶(~1%) |
| 数据接入 | 两融余额接入 macro/fetcher.py（2012至今） | D类信号数据基础 |

**2015 专项回测（2013-2018，CSI300）:**

| 版本 | 累计收益 | 最大回撤 | α vs B&H | 卖出 |
|------|------|------|------|------|
| v3 | +28.94% | -39.96% | +3.26% | 0次（满仓扛股灾） |
| v4 | **+63.79%** | **-19.28%** | **+38.11%** | 3次（5/6/7月 @ 4750/5076/4253点） |

**2018-2026 全周期：** +61.67% | α +27.71% vs 60/40 | 2021-03 逃顶卖出（5930点峰值次月）✅

**待研究（明天）：** 「两融出清」加分维度 — 能否捕捉2026-07/2024-02的V型底而不接2022/2023飞刀（详见 `backtest/margin_flush_study.py`）

### v5 (2026-08-17) — 分标的卖出 + 回补规则（实盘样本驱动）

**实盘首个样本暴露的结构性问题**：趋势破坏兜底只看 CSI300 趋势+PE，却一刀切作用于中证2000 仓位。
2026-08-17 开盘按信号减仓 159531 50%，当日中证2000 +2.4%（8月以来 +13%、8/12 已回站自身 MA60），
而 CSI300 仍在自身 MA60 下方 -0.9%——大盘弱≠小盘弱，卖出端必须跟上买入端"两个市场分开对待"的哲学。

**三个改动：**

| 模块 | 优化 | 效果 |
|------|------|------|
| 卖出信号 | 分标的判断：沪深300仓位看 `csi300_daily`，中证2000仓位看 `etf_159531` 日线 | A/B/D类+趋势兜底按持仓标的各自计算；C类宏观恶化全市场共享 |
| 卖出信号 | +回补规则：趋势破坏减仓后，标的回站MA60且MA60拐头向上 → 回补信号（`signal_type=trend_recovery`） | 减仓有了退出机制；近250交易日无趋势破坏则不算"回补" |
| 估值门槛 | 保留 CSI300 PE>60% 分位作为全市场背景条件 | "PE<60% 永不激活"的保险丝语义不变 |
| 数据治理 | 宁缺毋滥规则代码化：≤7天正常、7~20天警告、**>20天直接抛弃**；国债三级新鲜源链条（主源→缓存→bond_spread），冻结源永久移除 | 杜绝静默使用停更数据（8/17晚曾降级到2021年冻结的3.12%） |

**回测兼容**：不传 `daily_2000` 时输出与 v4 完全一致（单元测试逐字段校验）；既有回测全部走旧路径，历史结果不变。

**测试**：`tests/test_sell_signal.py`（10 例，含 8/14 实盘场景回归：300=SELL / 2000=HOLD）+ `tests/test_data_freshness.py`（12 例数据治理）。
