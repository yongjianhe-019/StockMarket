# 择时策略：冰点买入 + 泡沫卖出

基于 **A股估值指标 + 全球宏观指标** 双引擎的 ETF 左侧投资系统。

## 投资哲学

```
不做个股 → ETF 降噪
不做高频 → 月度信号
不做右侧追涨 → 左侧等冰点
不凭感觉 → 量化驱动

冰点出现 → 分批买入 → 长期持有 → 泡沫出现 → 减仓
```

## 信号定义

### 🧊 冰点（买入）

| ETF | 触发条件 | 含义 |
|---|---|---|
| 沪深300 | 分数 ≥ 50（PE/PB分位+回撤+量价+波动） | 估值便宜，左侧建仓 |
| 中证2000 | 分数 ≥ 50（宏观流动性+趋势动量+相对强弱） | 流动性充裕+趋势向好 |

### ⚠️ 泡沫（卖出）

**前提：PE 分位必须 > 60%（估值必须先贵）**

四分类检测，≥2 类触发 → 泡沫确认：

| 类别 | 信号 |
|---|---|
| A 价格加速 | 6月涨幅>30% / 偏离MA60>30% / 动能衰竭 |
| B 量价背离 | 近高点量缩 / 价升量缩 / 天量后急缩 |
| C 宏观恶化 | 利差扩大 / 人民币贬值 / 黄金飙升 / M2收紧 / 加息 / 社融收缩 |
| D 流动性狂热 | 两融6月增速>50% / 成交量20日vs年均>2.5倍 |

### 📉 趋势破坏（独立风控信号，非泡沫）

PE 分位 > 60% 且 跌破MA60且MA60拐头 → 减仓50%（检测器漏判时的保险丝，PE<60%永不激活）

### — 持有

两个极端信号（冰点/泡沫）均未触发 → 中间态，不操作。

## 模型优化日志

### v3 (2026-08-11) — 冰点增强 + 泡沫检测重写

**核心原则不变：左侧冰点播种，泡沫分批收割。**

四个优化：

| 模块 | 优化 | 来源 | 效果 |
|------|------|------|------|
| CSI300 冰点 | +ERP极端信号加分(+15) | 广发证券：ERP达均值+2σ是历史大底 | 深冬识别更准（2022年最高90分） |
| CSI300 冰点 | +宏观底部确认加分(+5) | 华泰证券：PMI/M2不再恶化=底部确认 | 微观估值+宏观共振 |
| CSI2000 冰点 | +趋势质量过滤(R²<0.3动量打折) | 小盘反弹假信号多 | 买入从16次降至14次，去噪音 |
| 泡沫检测 | 三分类确认：A价格加速+B量价背离+C宏观恶化 | 广发/东吴/经典量价 | 12年检测到14次部分信号，0次误触 |

**泡沫分级卖出机制：**

| 等级 | 条件 | 卖出比例 |
|------|------|:--:|
| 轻度泡沫 | 2类触发，3~4个信号 | 25% |
| 中度泡沫 | 2类触发，5~6个信号 | 50% |
| 严重泡沫 | ≥2类触发，7+个信号 | 75% |

**冰点分档买入机制：**

| 分数 | 季节 | 仓位 |
|------|------|:--:|

### v4 (2026-08-12) — 泡沫检测补盲区 + 信号分层 + 数据可靠性治理

**v3 病灶暴露（2015专项回测）**：2015股灾前泡沫检测 0 次触发，满仓扛过 -45% 回撤。
根因：B类量价背离/C类宏观恶化在杠杆快泡沫中永不触发（2015是量价齐升+宏观无恙），≥2类确认门槛永远凑不满。

**五个改动：**

| 模块 | 优化 | 效果 |
|------|------|------|
| 泡沫检测 | +D类「流动性狂热」：两融6月增速>50% + 成交量20日/年均>2.5倍 | 识别2015式杠杆快泡沫（两融数据源：证金公司官方，日频T日盘后） |
| 泡沫检测 | +趋势破坏兜底：PE>60%分位 + 跌破MA60且拐头 → 减仓50% | A/B/C/D全部漏判时的保险丝；PE<60%时永不激活（不会在便宜大底误卖） |
| 信号分层 | 泡沫(`signal_type=bubble`) 与 趋势破坏(`signal_type=trend_breakdown`) 分开命名 | 两个极端信号（冰点/泡沫）+ 独立风控信号，中间态不操作 |
| 数据治理 | 新开户数信号弃用（东财管道2023-08后冻结） | 管道不可信的数据宁缺毋滥；移除后2015卖出全保留，仅丢2021-03逃顶(~1%) |
| 数据接入 | 两融余额接入 macro/fetcher.py（2012至今） | D类信号数据基础 |

**2015 专项回测（2013-2018，CSI300）:**

| 版本 | 累计收益 | 最大回撤 | α vs B&H | 卖出 |
|------|------|------|------|------|
| v3 | +28.94% | -39.96% | +3.26% | 0次（满仓扛股灾） |
| v4 | **+63.79%** | **-19.28%** | **+38.11%** | 3次（5/6/7月 @ 4750/5076/4253点） |

**2018-2026 全周期：** +61.67% | α +27.71% vs 60/40 | 2021-03 逃顶卖出（5930点峰值次月）✅

**待研究（明天）：** 「两融出清」加分维度 — 能否捕捉2026-07/2024-02的V型底而不接2022/2023飞刀（详见 `backtest/margin_flush_study.py`）

### v5 (2026-08-17) — 分标的卖出 + 回补规则（实盘样本驱动）

**实盘首个样本暴露的结构性问题**：趋势破坏兜底只看 CSI300 趋势+PE，却一刀切作用于中证2000 仓位。
2026-08-17 开盘按信号减仓 159531 50%，当日中证2000 +2.4%（8月以来 +13%、8/12 已回站自身 MA60），
而 CSI300 仍在自身 MA60 下方 -0.9%——大盘弱≠小盘弱，卖出端必须跟上买入端"两个市场分开对待"的哲学。

**三个改动：**

| 模块 | 优化 | 效果 |
|------|------|------|
| 卖出信号 | 分标的判断：沪深300仓位看 `csi300_daily`，中证2000仓位看 `etf_159531` 日线 | A/B/D类+趋势兜底按持仓标的各自计算；C类宏观恶化全市场共享 |
| 卖出信号 | +回补规则：趋势破坏减仓后，标的回站MA60且MA60拐头向上 → 回补信号（`signal_type=trend_recovery`） | 减仓有了退出机制；近250交易日无趋势破坏则不算"回补" |
| 估值门槛 | 保留 CSI300 PE>60% 分位作为全市场背景条件 | "PE<60% 永不激活"的保险丝语义不变 |
| 数据治理 | 宁缺毋滥规则代码化：≤7天正常、7~20天警告、**>20天直接抛弃**；国债三级新鲜源链条（主源→缓存→bond_spread），冻结源永久移除 | 杜绝静默使用停更数据（8/17晚曾降级到2021年冻结的3.12%） |

**回测兼容**：不传 `daily_2000` 时输出与 v4 完全一致（单元测试逐字段校验）；既有回测全部走旧路径，历史结果不变。

**测试**：`tests/test_sell_signal.py`（10 例，含 8/14 实盘场景回归：300=SELL / 2000=HOLD）+ `tests/test_data_freshness.py`（12 例数据治理）。

### v8 (2026-09-21) — 修复 CSI300 分位窗口 bug（"5年分位"误用成"21.5年分位"）

**实盘复盘发现**：9/11、9/14 两笔沪深300买入后价格继续下探，归因发现信号本身是错的。

**根因**：估值源 `legulegu` 返回**月频**数据（`valuation_000300.parquet` 258行 / 2005–2026），
但 `compute_csi300_score` 按"5年×252=1260行"取窗，`_compute_series_pct` 在行数不足时
**静默回退用全部行** → "5年分位"实际是"21.5年分位"（含 2007/2015 泡沫）：

| 维度 | 真5年 | 实际(21.5年) | 后果 |
|---|---|---|---|
| PE分位 | 76.7% | 58.4% | 显得便宜 |
| PB分位 | 71.7% | 31.5% | 显得便宜 |
| 估值温度 | 0分 | 10分 | **虚增 +10** |
| ERP分位 | 37% | 72% | 显得有性价比 |
| 股债性价比 | 0分 | 15分 | **虚增 +15** |

→ CSI300 分数虚增 **25 分**，在回撤仅 11%（历史低胜率区）假触发冰点 BUY。

**修复**：

| 项 | 内容 |
|---|---|
| 分位窗口 | 新增 `_window_pct`，按**日期**取近5年（与数据频率无关）；观测 < `MIN_WINDOW_OBS=24` 则维度降级，**绝不静默回退全历史** |
| 估值新鲜度 | 估值滞后 > `VAL_MAX_STALE_DAYS=45` 天 → 弃用 + 告警（对齐数据铁律） |
| 覆盖范围 | 估值温度 / 股债性价比 / ERP极端信号 三处全部改用日期窗口 |

**效果（复现）**：2026-09-02~09-18，CSI300 由 51–60分 冰点✅ → **25–35分 冰点❌**；
CSI300-only 组合回测（2018–2026）不劣化（+28.7% → +30.5%）。

**测试**：`tests/test_csi300_window.py`（3 例，锁死窗口=5年 + 数据不足必须降级）。

**局限 / 待办**：这是**纠错**（消除假信号），整体胜率并未因此提升；趋势 regime 过滤
（`models/regime.py` + `backtest/regime_meta_backtest.py`）已验证为稳健的风险杠杆，
但**未接入生产**，待独立评审后再定。

### v8.1 (2026-09-21) — 卖出端同类 bug 修复（PE 分位窗口）

**排查发现**：`macro/sell_signal.py::_pe_percentile` 与买入端同病——CSI300 估值源为
月频（约258行/21.5年），旧实现 `len<252` 判定后用**全量**分位，把"偏贵"算成"合理"。

**影响（关键）**：泡沫/趋势破坏的**前提门槛是 PE 分位 > 60%**。修复前后：
- 2026-09-21：21.5年口径 **52.7%**（门槛关闭）→ 正确5年口径 **75.8%**（门槛打开）
- 修复后 `detect_bubble` 在 2026-09-21 触发 **CSI300 趋势破坏·减仓50%**
  （跌破MA60且MA60拐头 + 利差扩大）——即**卖出端的风控保险丝此前被 bug 抑制**。

**修复**：`_pe_percentile` 改为按**日期**取近5年（`PE_LOOKBACK_YEARS=5`），观测
< `PE_MIN_OBS=24` 则返回 None（门槛失效=不误开）。

**测试**：`tests/test_sell_signal_pe.py`（3 例）。

### v9 (2026-09-21) — 机会发现层：值得博弈的冰点买点

**动机**：CSI300 老冰点用固定分数≥50（刻舟求剑），不区分标的、不算性价比。
新层把入场判据换成 **R:R（性价比）+ 条件胜率 + EV + 企稳确认**，仓位用分数凯利。

**框架**（`models/opportunity_entry.py`）：
- 风险 = 现价 − 近20日低；回报 = 近120日高 − 现价；R:R = 回报/风险
- 条件胜率 p = 历史 (回撤档 × regime) 未来60日胜率（walk-forward，embargo=60）
- EV = p×回报 − (1−p)×风险；**值得博弈 = EV>0 且 R:R≥1.5 且 现价>MA20**
- 仓位 = 分数凯利，封顶50%；Wilson 下界≤50% 再打对折

**回测（沪深300，2023-10~2026-09，10%止盈半仓、仓位25%，只换入场逻辑）**：

| 入场逻辑 | 收益 | 最大回撤 | 信号 | 命中+10% |
|---|---|---|---|---|
| 老冰点(分数≥50) | +27.6% | -14.4% | 7 | 100% |
| **新机会发现(值得博弈)** | **+31.9%** | **-13.7%** | **10** | 90% |

→ 收益 +4.3pp、回撤更低、多抓 3 次机会。

**近3年按月（10%止盈半仓）**：CSI300 +16.5%/-8.7%、CSI2000 +37.2%/-18.2%、组合 **+27.2%/-12.1%**。

**接入**：`dashboard.py` 新增「🎯 值得博弈的冰点买点」区块；`find_opportunity.py` 独立扫描器（exit 1=有机会）。

**测试**：`tests/test_opportunity_entry.py`（7 例）。

**待改进（下一步）**：7月"未企稳就买"的痛（右侧确认可缓解）；CSI300 2026-08-07 那笔现亏。
样本外胜率 CSI300 45% / CSI2000 60%——**CSI300 仍偏弱，是下一轮优化重点**。
