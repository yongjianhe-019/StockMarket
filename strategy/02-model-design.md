# 量化模型设计文档

> 版本 v1.0 | 2026-08-10

## 一、模型原理

### 投资哲学

```
不做个股 → ETF 降噪（过滤个股黑天鹅）
不做高频 → 月度信号（过滤日间噪音）
不做右侧 → 左侧等冰点（便宜才买，不追涨）
不凭感觉 → 双引擎量化（A股指标 + 宏观指标）
```

### 核心逻辑

```
冰点买入 → 长期持有 → 泡沫卖出

冰点 = 足够便宜（A股指标）+ 宏观没崩（宏观指标）
泡沫 = 估值贵（A股指标）+ 宏观恶化（宏观指标）
其他 = 持有不动
```

## 二、双引擎架构

### 引擎1：A股指标打分

#### CSI300 估值驱动模型（5维度，100分）

| 维度 | 权重 | 指标 | 数据源 |
|---|---|---|---|
| 估值温度 | 30 | PE/PB 滚动5年分位 | akshare stock_index_pe_lg/pb_lg |
| 股债性价比 | 25 | ERP = 1/PE - 10Y国债收益率 | akshare bond_china_yield |
| 回撤深度 | 20 | 1 - 现价/近1年最高价 | akshare stock_zh_index_daily |
| 量价衰竭 | 15 | 近10日/120日均量 + 换手率分位 | akshare stock_zh_index_daily |
| 波动收敛 | 10 | 20日波动率/60日波动率高点 | akshare stock_zh_index_daily |

**分数释义：**
- < 50: 不便宜，等待
- 50-65: 秋末，关注
- 65-80: 冬天，首次建仓
- > 80: 深冬，补仓

#### CSI2000 流动性+动量模型（4维度，100分）

| 维度 | 权重 | 指标 | 数据源 |
|---|---|---|---|
| 宏观流动性 | 35 | M2增速 + 社融方向 + 中美利差 | akshare macro_china_* |
| 趋势动量 | 30 | 均线位置 + 3月收益 + 趋势R² | akshare csindex |
| 相对强弱 | 20 | CSI2000/CSI300比值分位 | akshare csindex |
| 市场结构 | 15 | 波动率收敛 + 成交量趋势 | akshare csindex |

**为什么不用PE？** CSI2000是微盘指数，成分股盈利不稳定，PE失真。改用流动性+动量驱动。

### 引擎2：宏观指标

#### 数据覆盖（23个因子）

| 类别 | 因子 | 频率 | 更新 |
|---|---|---|---|
| 汇率 | USD/CNY, JPY/CNY | 日 | ✅ 实时 |
| 利率 | 中国10Y/2Y, 美国10Y/2Y, 中美利差 | 日 | ✅ 实时 |
| 利率 | 中美期限利差(10-2Y) | 日 | ✅ 实时 |
| 商品 | 上海黄金 | 日 | ✅ 实时 |
| 货币 | M2同比, M1-M2剪刀差 | 月 | ⚠️ 滞后 |
| 信用 | 社融, 新增信贷 | 月 | ⚠️ 滞后 |
| 通胀 | CPI, PPI | 月 | ⚠️ 滞后 |
| 景气 | PMI制造业 | 月 | ⚠️ 滞后 |
| 地产 | 房地产景气, 70城房价 | 月 | ⚠️ 滞后 |
| 消费 | 社会消费品零售 | 月 | ⚠️ 滞后 |
| 海外 | 美联储利率 | 6周 | ⚠️ 滞后 |

#### 宏观在模型中的作用

- **冰点确认**：A股说便宜了，宏观看有没有系统性风险（信用崩/汇率崩/利差崩）
- **泡沫检测**：PE必须贵（>60%分位），加上宏观恶化才触发卖出
- **风格轮动**：M2↑→小盘强，PPI↑→大盘强

## 四、信号生成流程

```
每月1号:
  1. 拉取最新数据（A股 + 宏观）
  2. CSI300 打分 → 分数≥50?
  3. CSI2000 打分 → 分数≥50?
  4. 泡沫检测 → PE>60%分位 + 宏观恶化?
  5. 输出: BUY / HOLD / SELL

  冰点 → 分批买入（每次≤可用现金25%）
  泡沫 → 减半仓
  其他 → 不动
```

## 六、迭代优化指南

### 可调参数

| 参数 | 位置 | 说明 |
|---|---|---|
| 冰点阈值(50) | `strategy.py::is_ice_point` | 提高=更保守，降低=更积极 |
| CSI300 PE窗口(5年) | `models/csi300.py::LOOKBACK_YEARS` | 拉长=PE中枢上移 |
| CSI2000 宏观权重(35) | `models/csi2000.py::_score_macro_liquidity` | M2/信用/利差的分配 |
| 泡沫PE阈值(60%) | `macro/sell_signal.py::is_bubble` | 提高=更晚卖出 |
| 买入比例(25%) | `dashboard.py` | 每次加仓比例 |
| 宏观恶化阈值 | `macro/sell_signal.py` | 各警告信号的触发条件 |

### 如何优化

1. **新增因子**: 在 `macro/fetcher.py` 添加数据源，在 `models/` 加入打分维度
2. **调整权重**: 修改 `FACTOR_WEIGHTS` 或在各 `compute_*_score` 函数中调整
3. **回测验证**: `python backtest.py` 跑全周期，看 α 变化
4. **样本外测试**: 用最近1年数据做 walk-forward 验证

### 已知局限

1. CPI/PPI 数据滞后（akshare 免费版限制）
2. CSI2000 估值数据仅20天
3. 回测周期较短（ETF上市时间短）
4. 模型在单边牛市中跑输满仓持有（这是左侧策略的固有特性）
