## 一、投资哲学

### 核心理念

不做个股，不做高频，不做右侧追涨。用 ETF 过滤个股噪音，用"季节思维"过滤每日噪音，用左侧打分寻找最佳买入时机。

| 原则 | 说明 |
|---|---|
| **只做 ETF** | CSI 300（白马蓝筹）+ CSI 2000（微盘高波动），分散风险 |
| **季节判断** | 只看周/月级别的慢变量，不看日级别的"天气" |
| **左侧交易** | 便宜时买，越便宜越买，等待均值回归 |
| **长期持仓** | 不频繁交易，耐心持有到目标收益 |
| **量化驱动** | 多维度信号共振才动手，不拍脑袋 |

### 为什么是这两个 ETF

| | CSI 300 | CSI 2000 |
|---|---|---|
| 类型 | 大盘蓝筹 | 小微盘 |
| 波动 | 温和 | 剧烈 |
| 估值数据 | PE/PB 靠谱 | PE 失真，用 PB + 量价 |
| 在组合中的角色 | 底仓（稳） | 弹性仓（收益增强） |
| 分析重点 | 估值驱动 | 量价驱动 |

## 二、模型架构

### 整体逻辑

```
每周五收盘后运行
         │
   ┌─────┴─────┐
   ▼           ▼
CSI 300     CSI 2000
独立打分     独立打分
   │           │
   ▼           ▼
各自输出信号（等/关注/建仓/补仓/止盈）
```

### 信号分级（两个 ETF 共用）

| 总分区间 | 季节 | 含义 | 操作 |
|---|---|---|---|
| 0 - 50 | 夏天/秋天 | 不便宜 | 什么都不做，继续等 |
| 50 - 65 | 秋末 | 有点便宜了 | 关注，准备资金 |
| 65 - 80 | 冬天 | 很便宜 | **首次建仓**（计划仓位 1/3） |
| > 80 | 深冬/极寒 | 极度低估 | **补仓**（再买 1/3） |

**卖出条件（满足任一）：**
- 持仓收益 ≥ 20% → 分批止盈
- 总分降至 30 以下（估值修复完毕） → 清仓

## 三、CSI 300 打分模型

CSI 300 是白马股指数，PE/PB 估值数据可靠，**以估值为核心 + 量价辅助**。

### 打分表（满分 100）

| # | 维度 | 权重 | 指标 | 计算方法 |
|---|---|---|---|---|
| 1 | 估值温度 | 30 | PE + PB 滚动 5 年分位 | `(PE_pct + PB_pct) / 2`，分位越低分数越高 |
| 2 | 股债性价比 | 25 | 股权风险溢价 (ERP) | `ERP = (1/PE) − 10Y国债利率`，ERP 分位越高分数越高 |
| 3 | 回撤深度 | 20 | 近 1 年最大回撤 | `(1 − 现价/近1年高点) × 100%`，回撤越深分数越高 |
| 4 | 量价衰竭 | 15 | 成交额 + 换手率 | 成交额缩至半年均量 60% 以下 + 换手率历史分位 < 20% |
| 5 | 波动收敛 | 10 | 波动率冲高回落 | 近 20 日波动率从阶段高点回落 50% 以上 |

### 各维度评分细则

#### 1. 估值温度（30 分）

```python
PE_pct = PE_滚动5年分位数  # 越低越便宜
PB_pct = PB_滚动5年分位数
avg_pct = (PE_pct + PB_pct) / 2

if avg_pct < 0.10:   score = 30   # 极度低估
elif avg_pct < 0.20: score = 24
elif avg_pct < 0.30: score = 18
elif avg_pct < 0.50: score = 10
else:                score = 0    # 不便宜
```

#### 2. 股债性价比（25 分）

```python
ERP = (1 / PE) - 10Y国债收益率
ERP_pct = ERP_滚动5年分位数  # 越高越好（股票相对债券越便宜）

if ERP_pct > 0.90:   score = 25
elif ERP_pct > 0.80: score = 20
elif ERP_pct > 0.70: score = 15
elif ERP_pct > 0.50: score = 8
else:                score = 0
```

#### 3. 回撤深度（20 分）

```python
drawdown = 1 - 现价 / 近252交易日最高价  # 近1年

if drawdown > 0.30:  score = 20
elif drawdown > 0.20: score = 15
elif drawdown > 0.10: score = 10
elif drawdown > 0.05: score = 5
else:                 score = 0
```

#### 4. 量价衰竭（15 分）

```python
vol_ratio = 近10日均成交额 / 近120日均成交额
turnover_pct = 换手率_滚动2年分位数

# 地量见地价
if vol_ratio < 0.60 and turnover_pct < 0.20: score = 15
elif vol_ratio < 0.75 and turnover_pct < 0.35: score = 10
elif vol_ratio < 0.90: score = 5
else: score = 0
```

#### 5. 波动收敛（10 分）

```python
vol_20d = 近20日波动率
vol_high = 近60日波动率最高值

if vol_20d < vol_high * 0.50:  score = 10   # 恐慌消退
elif vol_20d < vol_high * 0.70: score = 6
elif vol_20d < vol_high * 0.85: score = 3
else: score = 0
```

## 四、CSI 2000 打分模型

CSI 2000 是微盘股指数，成分股盈利不稳定，PE 失真。**以量价为核心 + PB 辅助估值**。

### 打分表（满分 100）

| # | 维度 | 权重 | 指标 | 计算方法 |
|---|---|---|---|---|
| 1 | 回撤深度 | 30 | 近 1 年最大回撤 | 微盘波动大，回撤阈值设更高 |
| 2 | 量价冰点 | 25 | 成交额 + 换手率同时冰点 | 量缩 + 换手率历史底部 |
| 3 | 波动收敛 | 20 | 波动率冲高回落 + 横盘确认 | 恐慌释放后进入平静期 |
| 4 | 相对强弱 | 15 | CSI 2000 / CSI 300 比值分位 | 小盘相对大盘处于历史低位 |
| 5 | 估值参考 | 10 | PB 滚动 5 年分位 | 不用 PE，微盘盈利不稳定 |

### 各维度评分细则

#### 1. 回撤深度（30 分）

```python
drawdown = 1 - 现价 / 近252交易日最高价

if drawdown > 0.40:  score = 30   # 微盘跌40%很正常
elif drawdown > 0.30: score = 24
elif drawdown > 0.20: score = 16
elif drawdown > 0.10: score = 8
else:                 score = 0
```

#### 2. 量价冰点（25 分）

```python
vol_ratio = 近10日均成交额 / 近120日均成交额
turnover_pct = 换手率_滚动2年分位数

if vol_ratio < 0.50 and turnover_pct < 0.10: score = 25    # 极度冷清
elif vol_ratio < 0.60 and turnover_pct < 0.20: score = 20
elif vol_ratio < 0.75 and turnover_pct < 0.35: score = 12
elif vol_ratio < 0.85: score = 5
else: score = 0
```

#### 3. 波动收敛（20 分）

```python
vol_20d = 近20日波动率
vol_high = 近60日波动率最高值
price_range = 近10日价格振幅 / 近10日均价

# 波动回落 + 价格横盘 = 底部确认
if vol_20d < vol_high * 0.50 and price_range < 0.05: score = 20
elif vol_20d < vol_high * 0.60: score = 14
elif vol_20d < vol_high * 0.75: score = 8
else: score = 0
```

#### 4. 相对强弱（15 分）

```python
ratio = CSI2000指数点位 / CSI300指数点位
ratio_pct = ratio_滚动3年分位数  # 越低说明小盘越被抛弃

if ratio_pct < 0.10:  score = 15   # 小盘极度弱势，可能是底部
elif ratio_pct < 0.20: score = 12
elif ratio_pct < 0.35: score = 8
elif ratio_pct < 0.50: score = 4
else: score = 0
```

#### 5. 估值参考（10 分）

```python
PB_pct = PB_滚动5年分位数

if PB_pct < 0.15:  score = 10
elif PB_pct < 0.25: score = 7
elif PB_pct < 0.40: score = 4
else: score = 0
```

## 五、交易执行规则

### 资金分配

| ETF | 角色 | 资金占比 |
|---|---|---|
| CSI 300 | 底仓（稳） | 60% |
| CSI 2000 | 弹性仓（收益增强） | 40% |

### 建仓

| 触发条件 | 操作 | 仓位 |
|---|---|---|
| 总分 65-80（冬天） | 首次建仓 | 该 ETF 计划仓位的 1/3 |
| 总分 > 80（深冬） | 补仓 | 再买 1/3 |
| 总分继续上升 | 越跌分越高，可继续补 | 最多买到该 ETF 计划仓位的 100% |

### 止盈

```
条件：持仓收益 ≥ 20%

方式：分批止盈
  - 达到 20% 收益 → 卖出 1/3
  - 达到 30% 收益 → 再卖出 1/3
  - 总分降至 30 以下（不便宜了）→ 清仓剩余
```

### 止损

```
左侧交易不做硬止损（容忍短期亏损）。

唯一清仓条件（和止盈无关）：
  - 模型基础逻辑被打破（如指数编制规则大改）
  - 黑天鹅事件导致 ETF 流动性枯竭
```

## 六、运行频率

| 操作 | 频率 | 说明 |
|---|---|---|
| 数据拉取 | 每周五收盘后 | akshare 获取指数行情、估值、成分数据 |
| 打分计算 | 每周一次 | 两个 ETF 独立计算，输出各自总分 |
| 信号决策 | 每周一次 | 对比总分与阈值，判断是否触发操作 |
| 人工确认 | 每次操作前 | 模型给信号，人做最终决策（初期） |
